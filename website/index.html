Claude Code plugin · free & open source

Write your book with Claude. In your voice.

Ghost Writer turns Claude into a demanding co-author: it asks before it writes, drafts in your voice, then tears the draft apart so your readers don't have to.

The method

Claude formalizes. You invent.

Born writing Quantum Fatalism, a philosophical essay written in explicit collaboration between a human author and Claude. Every chapter goes through the same four-step cycle.

Ask

A structured dialogue, one question at a time, before a single line is written.

Write

The draft is generated in your voice fingerprint, following your style rules.

Demolish

Hostile critique across 7 vectors, plus 5 reader personas who don't love you.

Integrate

Your answers go back into the text — one change at a time, only with your approval.

Features

Everything a book needs, from first idea to podcast.

/ghost-writer:wizard

Guided onboarding

Author interview, book brainstorm and voice fingerprint from your writing samples. Start from nothing.

/ghost-writer:chapter

Full chapter cycle

Dialogue, draft, demolition and integration in one command. Or drive each step yourself.

/ghost-writer:demolish

Hostile critique

Finds circular arguments, unearned endings and unsupported claims. --light for the 3 most critical issues.

/ghost-writer:review

5 reader personas

Target reader, hostile reader, domain expert, editor and out-of-target reader. Add your own.

/ghost-writer:graph

Book graph

A self-feeding map of characters, places, concepts and events — every fact cites a line and quotes it.

/ghost-writer:consistency-check

Continuity guard

Term drift, contradicted claims, broken promises, timeline and character details across chapters.

/ghost-writer:corrections

Re-read anywhere

Print a PDF with paragraph IDs, annotate on tablet, phone or paper, import the notes back.

/ghost-writer:session-start

Memory & resume

Terms, promises and demolition history are written down. Each session opens with a briefing in seconds.

/ghost-writer:export-epub

Manuscript & export

Arc audit and submission-ready manuscript. Export to PDF, EPUB and DOCX.

/ghost-writer:podcast

Book to podcast

Scripts adapted for the ear, offline TTS with Piper, original jingle, MP3 episodes and RSS feed.

/ghost-writer:site

Book website

A mobile-first page for GitHub Pages: cover, download, characters, podcast and the explorable graph.

/ghost-writer:freeflow

Writer's block mode

Dump everything you have in mind; the plugin organizes it into a chapter plan.

Principles

The rules it never breaks.

  • Claude formalizes, doesn't invent.
  • One question at a time. Always.
  • No change without your confirmation.
  • Demolition strengthens.
  • Memory is explicit.
  • The introduction is written last.

Install

Two commands in Claude Code.

Add the repository as a marketplace, then install the plugin.

# 1 — add the repo as marketplace
/plugin marketplace add simonediroma/claude-ghost-writer

# 2 — install the plugin
/plugin install ghost-writer@simonediroma-ghost-writer

Then verify the setup and start:

/ghost-writer:check   # verifies installation in 60 seconds
/ghost-writer:wizard  # conversational setup from scratch
