# Privacy Policy — Ghost Writer

_Last updated: November 24, 2026_

Ghost Writer is an open-source plugin for Claude Code. This policy explains what data the plugin handles.

## Data collection

The plugin itself does **not** collect, store, transmit or sell any personal data. It has no analytics, telemetry, tracking, accounts or servers of its own.

## Where your data lives

Everything the plugin creates — author profile, book configuration, voice sample, chapters, memory files, session notes and exports — is saved as plain files **in your local project folder**. You own these files and can edit or delete them at any time.

## Claude and Anthropic

The plugin runs inside Claude Code. The text you write and the files the plugin reads are processed by Claude, under [Anthropic's Privacy Policy](https://www.anthropic.com/legal/privacy) and the terms of your Claude plan. The plugin does not send your data anywhere else.

## Optional downloads and publishing

- **Podcast** (`/ghost-writer:podcast`): text-to-speech runs offline (Piper). On first use, some optional music features download free sample libraries (e.g. VCSL, Growlybass) from GitHub. These downloads contain no data about you.
- **Website and podcast feed** (`/ghost-writer:site`, `/ghost-writer:podcast`): content is published only if you choose to push it to a host you choose (e.g. GitHub Pages). That host's privacy policy then applies.

## Third-party services

The plugin needs no API keys and no paid services. Any third-party tool you install yourself (e.g. ffmpeg, Pandoc, ACE-Step) is covered by its own license and policy.

## Changes

Changes to this policy are published in this file and tracked in the repository history.
